FAQ

Common questions.

Everything you need to know before subscribing.

How is the data delivered?

Immediately after subscribing, you receive a share link to a live Google Sheet. Bookmark it — the data refreshes automatically every day at 6:00 AM ET.

Where does the data come from?

Public Franklin County and Columbus-area records: property transfers, tax data, sheriff sales, GIS parcels, zoning, and permits. We clean, score, and cross-reference it for you.

Can I cancel anytime?

Yes. This is a month-to-month subscription. You can cancel through Stripe at any time and keep access until the end of your current billing period.

Is this legal to use for marketing or wholesaling?

The data is public record. Always verify details independently and comply with local solicitation, DNC, and real estate licensing laws before contacting owners.

Will the number of properties grow?

Yes. The daily sync adds new records as they hit the county, so the sheet grows over time. Current count: 184+ active scored properties.

Is there an API tier?

An $800/mo sheet + API tier and a $0.35/lookup x402 API are on the roadmap. For now, this subscription is Google Sheet access only.
